# Shimi Looks illustration

## Version 4.1.2

The selected full-body illustration is the exact approved JPEG, `assets/shimi-personal-v412.jpg`, at 853 × 1280 pixels. This source is copied without regeneration, rescaling, retouching or recompression. The selected face, hair, pose, proportions, necklaces and tattoos are retained.

The illustration wears a plain short-sleeve V-neck top, high-rise flowing wide trousers with a drawstring, and loafers. The three garments are recolored through registered `art-matte-*-v412.png` layers that encode the source fabric RGB and fractional coverage. The face, neckline skin, necklaces and tattoos are protected from recoloring. A subtle `denim-weave-v412.png` texture is confined to the trousers when denim is selected.

`art-background-v412.png` describes the source's external white backdrop. The display renderer blends this backdrop into the existing cream interface (#F7F3EC), leaving the source file intact. Main preview, enlargement and download use the same crop: x=170, y=0, width=446, height=1280. Only empty margins are cropped; the character is never distorted.

Development references, original photographs and rejected illustration variants are not included in this release package.
