# שימי בסטייל v27 — תצוגת לוק על דמות

מבוסס על v26, עם אותו עיצוב בסיסי וחוקי הצבע האחרונים.

מה חדש:
- נוספה תצוגה מאוירת של דמות במרכז הלוק.
- הצבעים של הלוק נצבעים ישירות על הדמות:
  - עליון
  - תחתון
  - נעליים
  - אביזר / תיק
- התצוגה מופיעה גם בלוק היומי וגם במסך “בחרתי משהו”.
- נשמרו כל החוקים האחרונים:
  - אין חוק מיוחד לורוד או ירוק בנעליים.
  - נעליים מגוונות באמת בין כל הצבעים האפשריים.
  - נעליים לא חוזרות על אותו צבע בהצעות קרובות.
  - כל צבעי הנעליים אפשריים חוץ מטורקיז ומנטה.
  - מנטה בחוץ מהפלטות/ההצעות.
  - אביזר אדום בערך פעם ב־6 לוקים.
  - נעלי אדום בערך פעם ב־10 לוקים.
  - לא אדום גם בנעליים וגם באביזר באותו לוק.
