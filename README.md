# Shimi Looks v31

- עליון = מלבן עליון
- תחתון = מלבן גדול
- נעליים = שני מלבנים קטנים
- אביזר = לב גדול צף
- בצד ימין/שמאל (לפי RTL) מופיע ההסבר של כל חלק

- אדום מרוסן
- נעליים מגוונות
- מנטה וטורקיז בחוץ
