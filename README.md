# שימי בסטייל v26 — תיקון נקי בלי שינוי עיצוב

שינויים בלוגיקה בלבד:

- מנוע הנעליים מגוון באמת בין כל צבעי הנעליים האפשריים.
- נעליים לא חוזרות על אותו צבע בהצעות קרובות.

- אביזר אדום מרוסן: בערך פעם ב־6 לוקים.
- לא אדום גם בנעליים וגם באביזר באותו לוק.
- מנטה בחוץ מהפלטות/ההצעות.
- בנעליים: כל הצבעים אפשריים חוץ מטורקיז ומנטה.
