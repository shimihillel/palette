# Shimi Looks v7

גרסה נקייה ויציבה יותר.

## עדכונים
- הכפתור הראשי הוא **הבא בתור**.
- כפתור השמירה הוא **שומרת ♡**.
- אין יותר עמוד "עוד 3 שילובים".
- יש עמוד **בחרתי משהו** לבנייה סביב פריט קיים.
- ביטלתי cache/service worker כדי למנוע תקיעות ב-GitHub Pages.

## העלאה
להעלות את כל הקבצים ישירות לשורש הריפו:
- index.html
- style.css
- script.js
- manifest.webmanifest
- sw.js
- assets/


## עדכון v8
- תיקון חשוב במנוע הלוקים: העליון כבר לא ננעל על גוונים בהירים כמו שיבולת/שנהב/לבן פשתן.
- כל צבע בפלטה יכול להפוך לעליון.
- המיפוי לעליון/תחתון/נעליים/אביזר מגוון יותר, ועדיין מנסה להישאר לביש.


## עדכון v9
- תיקון אמיתי לבעיית העליון:
  - החלפתי את מפתח ה-localStorage כדי שהאפליקציה לא תמשיך להציג לוקים ישנים מהגרסה הקודמת.
  - העליון נבחר עכשיו בכוונה מצבעים שאינם בהירים ברוב המקרים.
  - הצעות עם עליון שנהב/שיבולת/פשתן מקבלות ניקוד נמוך, אז הן יופיעו רק לעיתים רחוקות.


## עדכון v10
- שינוי אמיתי במנוע: ברירת המחדל כבר לא כוללת שנהב/שיבולת/לבן פשתן.
- החלפתי את מתכוני הצבע כך שלא יתחילו מ-light בכלל.
- הוספתי כלל קשיח שמסנן צבעים בהירים מהפלטה החופשית.
- החלפתי localStorage key כדי שלא יוצגו לוקים ישנים שכבר נשמרו בדפדפן.


## עדכון v11
- החזרנו גוונים בהירים, אבל במינון נמוך ולא בכל הצעה.
- הורדנו מעט ורודים ושחורים.
- המנוע מוטה יותר לצבעי שימי: אדמה, חומים, ירוקים, בורדו, כחולים, קוניאק, חלודה, קקאו.
- צבע בהיר יכול להופיע לפעמים, בעיקר כאביזר/ריכוך, אבל לא כבסיס קבוע.
