# שימי סטייל — אפליקציית התאמות צבעים

גרסה סטטית להעלאה לגיטהאב / GitHub Pages.

## קבצים

- `index.html` — מבנה האפליקציה
- `style.css` — עיצוב
- `app.js` — לוגיקת התאמות צבעים
- `manifest.json` — PWA בסיסי
- `service-worker.js` — עבודה בסיסית אופליין

## חוקים אחרונים

### אדום

- אביזר אדום: בערך פעם ב־6 לוקים.
- נעליים אדומות: בערך פעם ב־10 לוקים.
- אדום לא חוזר אם הופיע ממש לאחרונה.
- אדום הוא accent בלבד, לא צבע שמשתלט על הלוק.

### נעליים מגוונות

- לא חוזרים על אותו צבע נעליים ברצף.
- יש העדפה לרוטציה רחבה של צבעי נעליים.
- אין חוק מיוחד לורוד או ירוק.
- כל צבעי הנעליים אפשריים כחלק מרוטציה אמיתית.
- לא חוזרים על צבעים לאחרונה יותר מדי; צבע שלא הופיע לאחרונה מקבל עדיפות קלה.
- שחור / לבן / בז׳ לא אמורים להשתלט רק כי הם צבעים בטוחים.
- מנטה וטורקיז מחוץ לרוטציית הנעליים.

### מנטה וטורקיז

- מנטה בחוץ לגמרי.
- טורקיז בחוץ מנעליים ומהצעות צבע.
- לא בבגדים, לא בנעליים, לא באביזרים.
